Ethics & consent

Bypass Robots.txt lets a run ignore a site's robots.txt disallow rules instead of refusing to visit those paths. Authorising captcha answering is a per-run consent, checked only when the pipeline actually contains a Solve Captcha step — and it is only half of what that step needs: the other half is a per-domain attestation set on the step itself, so turning this on here does not by itself authorise anything.

Schedules

Run the pipeline on this board on a timer. There is no server: Chrome has to be running for a schedule to fire, so one set for 3am runs at 3am if this machine is awake and does not if it is shut. A window that passes while the browser is closed is reported as missed rather than made up for — running the missed hours back to back would hammer the site.

Chrome will not fire an alarm more often than once a minute.
